Governed Execution

AIの判断をそのまま本番に流すのではなく、変更の追跡、実行の可視化、緊急停止、エビデンスの記録まで。Exastroが実行基盤として統制するから、安心してAIに任せられます。

  2. AI AGENT 理解・計画・判断
  3. CONTROL PLANE Exastro Control Plane 統制して実行する
  4. SYSTEMS 実システム

Exastro Control Plane を特徴づける8つの要素

01CHANGE CONTROL誰が・いつ・何を

現在だけでなく変更予定も含め、設定変更を構成情報として追跡する。

02REUSE FIRSTIaCを増殖させない

毎回生成する前に、検証済みの既存IaC・自動化部品を探して再利用する。

03SEPARATIONフローと構成を分離

設定値が変わってもジョブフローを作り直さず、同じ自動化を繰り返し使える。

04LIVE EXECUTION実行中が見える

いま何が、どこまで進んでいるかをリアルタイムに把握する。

05EMERGENCY CONTROLいつでも止められる

異常を検知したら、それ以上処理を進めないよう、実行基盤側で停止・中断できる仕組みを備える。

06EVIDENCE投入から結果まで残す

投入データ、実行結果、ログ、エビデンスを過去分まで紐付けて管理する。

07KNOWN / UNKNOWNAIを使うべき場面を選ぶ

ルールで既知事象と未知事象を判定し、決定論と推論を使い分ける。

08AUTO REMEDIATION既知は迷わず自動対処

既知事象には、登録済み・検証済みの対処業務を自動で実行する。

ここまでの仕組みは、実際の画面で動いています。

Vision

現場の苦労を、なんとかしたい。Exastroの各プロダクトは、運用・開発の現場に立つ開発者たちの、そんな思いから生まれました。

Exastroにかける夢吉田 功一

システムはどんどん複雑化し、人材はどんどん減ってゆく

業務は日々増えるのに、人材が不足すれば何が起こるか？今いる人に業務が集中し、疲弊していくことが目に見えています。疲弊している先輩方を見た若い人たちは、果たして「システムエンジニアになりたい」と思うでしょうか？誰が見てもかっこいいと思えるスマートな働き方を実現する手段になりたいと思っています。

また、Exastroは、単に負の連鎖から脱却することだけでなく、事業拡大に向けた新たな取り組みを行うことにも一役買いたいと思っています。
